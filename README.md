# Motnfs.Media

أرشيف ووسائط النشر لمتنفس (motnfs.com). يُدار آلياً من نظام المحتوى.

- `media/<YYYY-MM>/` ملفات النشر الأصلية (JPG ١٠٨٠ / MP4 ١٠٨٠×١٩٢٠ / PDF). اسم كل ملف فيه بصمة sha256 فلا تتكرر النسخ.
- `archive/<YYYY-MM>/<post-id>/post.md` أرشيف كل منشور: النصوص لكل منصة، التعليق الأول، الوسائط، المعرّفات، والأداء.
- `archive/index.csv` فهرس كل المنشورات.

الإعدادات (تشغيل/إيقاف، الجودة) في لوحة متنفس: config/media.
